Get Started
Setup guide

Install PiSTG on your Raspberry Pi

Follow these steps to get PiSTG running on your Pi. The included start script handles everything — it creates an isolated Python environment and installs dependencies automatically. No manual setup headaches.

Steps

  1. 1  Get the project
  2. 2  Run the start script
  3. 3  Open the dashboard
  4. 4  Log in & secure it

Reference

  1. What you get
  2. Notes & tips
1

Get the project on your Pi

Clone the Raspberry Pi interface server repository to your Pi. Make sure you have git installed — it comes pre-installed on Raspberry Pi OS.

Terminal 
git clone https://github.com/stghecker/raspberry-pi-interface-server.git

Then move into the project folder and the webserver subfolder:

Terminal 
cd raspberry-pi-interface-server/webserver
2

Run the start script

PiSTG includes a start script that handles everything for you. It creates an isolated Python environment (so you never hit the externally-managed-environment error) and installs the dependencies automatically.

Terminal 
chmod +x start.sh
./start.sh

The first run takes a little longer while it sets up the environment. After that, it starts instantly every time.

3

Open the dashboard

Once the server is running, open a browser on any device connected to the same network as your Pi and go to:

Browser 
http://<your-pi-ip>:5000

Not sure of your Pi's IP address? Run hostname -I in the terminal on your Pi.

4

Log in & secure it

The first time the server starts, a default admin account is created automatically. Use these credentials to log in:

Username admin
Password admin123

Log in and change the password right away from your profile page. Don't leave the default password on a network-connected device.

What you get

Live system info with graphs

CPU usage, memory, CPU temperature, disk, network traffic, and uptime — all updating in real time.

Online file explorer

Browse, download, upload, and delete files. Admins can manage which folders each user can access.

Multi-user with roles

An admin user can create users, assign folder access, change passwords, and edit profile names.

Mobile-friendly

Responsive layout that works great on phones and tablets, not just desktop browsers.

Notes & tips

Local database

User accounts and folder permissions are stored in a local SQLite database file called pi_dashboard.db.

Sandboxed files

The file explorer is sandboxed to the folders the admin allows for each user. Users can't reach outside their permitted folders.
